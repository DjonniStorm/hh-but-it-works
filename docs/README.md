# docs

Два контура: публичный сайт и внутренние заметки для разработки.

Публичный (VitePress, отдельный npm, не workspace): [`prod/`](prod/). На Vercel Root Directory = `docs/prod`. Разделы: как работает, локальный запуск, стек, ФСП, антисписывание, код, дорожная карта, ссылки. Стенд на сайте в подвале: [hire.eegov.net](https://hire.eegov.net).

Для правок кода: сначала [`dev/AGENT_HANDOFF.md`](dev/AGENT_HANDOFF.md) и [`../AGENTS.md`](../AGENTS.md), затем архитектура, модель, тесты кандидатов.
