# Backend

Основным инструментом для построение API в приложении является фреймворк Nest.js. Он предоставляет значительное количество встроенных и готовых решений.

Используется модульный монолитный подход, в котором мы старались уйти от высокой связности. В дальнейшем это позволит нам гораздо проще перейти на микросервисы.

Основные компоненты backend, которые мы используем:

- Сам Nest.js - Используем платформу над Express.js, для которой есть все нужные нам инструменты. В будущем сначала можно перейти на Fatify для ускорения работы
- BullMQ - очереди (перечислить какие. ..)
- TypeORM - ORM для работы с базой данных Postgres
- Redis - слой кеширования
- Nodemailer - работаем с почтовыми клиентами для отправки писем
- JWT и криптография пакетами passport.js и bcrypt (указать основные алгоритмы)
- Zod/TypeScript - переиспользуемый компонент всех пакетов
