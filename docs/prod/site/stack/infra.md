# Инфраструктура решения

## Организация кода

Для организации кода мы используем подход монорепозитория, при котором мы имеем возможность переиспользовать много кода без необходимости версионирования внешних библиотек. Все организует пакетный менеджер PNPM и его расширение для Workspace (перечислить основные воркспейсы). Это позволяет нам даже локально экономить место и удобно управлять используемыми пакетами.

## Сервисы и развертывание

Для быстрого развертывания мы используем Docker и docker compose.
Благодаря compose мы можем одной командой развернуть наше решение на удаленном сервере (hire.eegov.net)
(перечислить основнеы пакеты)

## Web server

Для организации web-сервера мы используем Caddy. Для нас была важна скорость и простая настройка. А также отдельным преимуществом для нас является автоматическое управление SSL сертификатами, где нам достаточно указать домен.
