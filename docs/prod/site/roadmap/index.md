# Roadmap

Что сознательно не делали в MVP и что ещё открыто. Без дат.

В схеме продукта помечено «не MVP»: публикация вакансии на доску, свой отклик кандидата, короткие задания сверх теста.

У ranking serving-бандл llm-approved (`ltr-v1.5.0-llm`). Следующая ступень: двойная human-разметка. Петля dismiss и invite для персонализации в формуле ещё не подключена.

GitHub Actions на аккаунте выключен. Образ ranking в GHCR с тегом `:dev` может отставать от репозитория. Локальная сборка копирует committed-артефакты и ничего не обучает при старте.

Публичная вакансия и свой отклик появятся, когда доска понадобится продукту. Сейчас рынок это приглашение из подборки.
